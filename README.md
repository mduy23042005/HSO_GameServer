# Installation Guide

## 1. Clone the repository

```bash
git clone https://github.com/mduy23042005/HSO_GameServer.git
```

---

## 2. Configure the Client

- Open the project with Unity.
- Open the scripts with Visual Studio.
- Configure the server connection to port **55556**.
- Build the project.

---

## 3. Run the Client

Before launching the client, make sure the backend services are running:

1. Start the **Web API**.
2. Start the **WebSocket Server**.
3. Launch the Unity project or the built executable.
4. Verify that the client successfully connects to the server.
